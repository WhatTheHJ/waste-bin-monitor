# waste-bin-monitor

## 1. 프로젝트 개요

수거업체가 쓰레기통 3개의 포화량을 한 화면에서 보고, 50·75·100%에 도달할 때마다 알림을 받아 수거 시점을 정하는 시스템입니다.

- **목표**: 통마다 초음파 센서로 포화량을 재고, 블루투스로 라즈베리파이 서버에 모아 MariaDB에 매시간 기록합니다. 단계별 알림과 도트매트릭스 관제 화면으로 "지금 어느 통부터 수거할지"를 바로 판단하게 합니다.
- **관점**: 사용자는 쓰레기를 버리는 사람이 아니라 **수거 담당자**입니다. 모든 기능은 효율적인 수거 경로와 시점을 정하는 데 맞춰져 있습니다.

## 2. 시스템 구성

쓰레기통마다 측정 노드가 하나씩 붙고, 세 노드가 각자의 HC-06으로 라즈베리파이에 값을 보냅니다. 판단·저장·표시·알림은 모두 서버가 맡습니다.
